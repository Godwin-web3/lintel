# Lintel brand kit v1.0

The lintel is the beam laid across two posts to make a doorway. It stands only when both posts carry it: buyer and seller each hold half of a signature, and neither settles alone.

Full guidelines: [Lintel-Brand-Guidelines.pdf](Lintel-Brand-Guidelines.pdf).

## Files

| Path | What |
| --- | --- |
| `logo/` | SVG mark, wordmark, lockup (`-dark` for dark backgrounds, `-light`, `-mono-bone`, `-mono-ink`), app icon, favicon |
| `png/` | PNG exports |
| `fonts/` | Geist, Geist Mono, Instrument Serif (WOFF2, SIL OFL) |
| `tokens.css` | Color, type and spacing tokens |
| `gen.py`, `og.py` | Regenerate logos and the social image |

## Color

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#0E0F11` | Page |
| Basalt | `#17191D` | Surfaces |
| Slate | `#2A2E35` | Hairlines |
| Ash | `#8C929C` | Secondary text |
| Bone | `#ECE6DA` | Primary text |
| Amber | `#F4B728` | Brand and the one value-moving action per screen |
| Verdigris | `#4FB38A` | Settled, verified |
| Lapis | `#7A9CF0` | Pending on chain |
| Oxide | `#E0604E` | Refund, error |

Roughly 80% stone, 15% bone, 5% amber.

## Type

Instrument Serif for headlines (28px and up), Geist for UI, Geist Mono for hashes, amounts, heights and labels.

## Don't

Rotate, stretch, recolor, outline, add shadows or glow to the mark, or retype the wordmark. Keep clear space of twice the beam height.
